# gradaran — WSET Level 3 self-study tutor pack

A shareable tutor pack for studying towards the **WSET Level 3 Award in Wines**. Give it to any AI agent and it tutors you through the syllabus, one lesson at a time, as a connected story — not a list to memorise.

## Who it is for

Anyone studying for WSET Level 3 who wants an AI tutor — in voice mode or in text mode (including text agents like Instinct). No prior progress is assumed; start at Chapter 1.

## 3 steps

1. **Copy/fork this repo to your own account first.** The shared copy has no personal progress, on purpose. Fork it (or copy `education/` into a new private repo), then copy the blank templates from `education/progress-templates/` into `education/` as `STATE.md`, `PROGRESS.md` and `SESSION_LOG.md`.
2. **Give the agent `education/AGENTS.md`.** That is the single source of truth. A new agent should start with `education/AGENT-QUICKSTART.md` (2–3 minutes), then skim `AGENTS.md` — it does not need to read 30+ files before its first session.
3. **Start Chapter 1.** Voice mode: spoken, 1–3 minute introductions, one question at a time. Text mode: short messages, one idea or question per message, plain text.


## Where NOT to start

- Do **not** study in the shared copy — copy/fork first, or your progress mixes with everyone else's.
- Do **not** start with the lesson plans, the audit files, or the knowledge notes. Start with `AGENT-QUICKSTART.md`, then `AGENTS.md`, then Chapter 1.
- Do **not** read all 30+ files first. The quickstart plus `AGENTS.md` is enough for a first session; the rest is looked up as needed.

## What is NOT included

No personal progress (that lives only in your own copy). No exam material verbatim — plans are written in original words, aligned with the WSET Level 3 specification (2022 Issue 2). Not affiliated with WSET.
