# Knowledge base — reference notes for the lesson plans

These notes support `education/lessons/`. They are not lessons themselves,
and reading them is not the same as passing a checkpoint. They are written
in original words, for study use, and they are organised for voice use:
each note starts with a short spoken summary, then the detail in plain
language. If a table would help on paper, the same information is also
given as sentences, so the note can be read aloud without a table.

Spoken summary of this folder, in order: climate types — how ocean,
inland distance, and summer-dry seasons shape ripening and risk.
The vine growth cycle — dormancy, budburst, flowering, fruit set,
véraison, ripening, and harvest, as a chain. Grape composition and
ripening — sugar, malic and tartaric acids, colour, tannin, and flavour,
and why sugar alone is not ripeness. Soil, water, and site — drainage,
root oxygen, vigour, aspect, slope, and frost pockets. Key grapes —
the varieties that recur across the syllabus, in causal terms.
Key regions at a glance — one spoken sketch per major region, for
comparison only. Tasting, using the Systematic Approach — appearance,
nose, palate, and conclusions, in order. And sweetness, sparkling, and
fortified terms — the vocabulary that confuses most often, explained
in plain language.

## How to use them in voice mode

Read the spoken summary aloud first. Then, only if the learner asks
for detail or shows a gap, read the relevant detail section aloud,
in your own words. Do not read a whole reference note as a lecture
unless the learner asks for it. The lesson plans in `lessons/` decide
what to teach next; these notes are the backup, not the curriculum.
