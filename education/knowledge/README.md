# Knowledge base — reference notes for the lesson plans

These notes support `education/lessons/`. They are not lessons themselves,
and reading them is not the same as passing a checkpoint. **Reference-only:
look up the one note for the lesson you are teaching; do not read the whole
folder to start.** They are written
in original words, for study use, and they are organised for both modes:
each note starts with a short summary, then the detail in plain
language. If a table would help on paper, the same information is also
given as sentences, so the note can be read aloud in voice mode, or sent
as short plain-text messages in text mode — no heavy tables in chat.

Spoken summary of this folder, in order: climate types — how ocean,
inland distance, and summer-dry seasons shape ripening and risk.
The vine growth cycle — dormancy, budburst, flowering, fruit set,
véraison, ripening, and harvest, as a chain. Grape composition and
ripening — sugar, malic and tartaric acids, colour, tannin, and flavour,
and why sugar alone is not ripeness. Soil, water, and site — drainage,
root oxygen, vigour, aspect, slope, and frost pockets. Key grapes —
the varieties that recur across the syllabus, in causal terms.
Key regions at a glance — one spoken sketch per major region, for
comparison only. Tasting, using the Systematic Approach — appearance,
nose, palate, and conclusions, in order. Sweetness, sparkling, and
fortified terms — the vocabulary that confuses most often, explained
in plain language. And history and fun facts — stories tied to chapters,
to be used sparingly, only where they advance the lesson's narrative.

## How to use them

Read the short summary first. Then, only if the learner asks for detail or shows a gap, go into the relevant detail section, in your own words. Do not read a whole reference note as a lecture unless the learner asks for it. The lesson plans in `lessons/` decide what to teach next; these notes are the backup, not the curriculum.

Teach from these notes as a story, not a list: each note explains a mechanism — what happens, why, and what it means for the wine. A fact earns its place only if it helps explain a wine style, quality or price.
